# Anjor Tank — portfolio

Personal site of Anjor Tank: product architect, GTM engineering and RevOps, and founder of ROQIVA (in development).
One story across ten pages: Work → GTM & RevOps → ROQIVA → Journey → Beyond → Hire → Contact.

Built with React, Vite and GSAP, prerendered per route (`scripts/site.mjs`). Content lives in `src/content/`.

    npm install
    npm run dev        # local
    npm run build      # build + per-route HTML, sitemap, llms.txt
    npm run check      # post-build checks

Canonical origin: https://anjor-portfolio.vercel.app (`src/content/site.js`). Contact: anjort2000@gmail.com.
